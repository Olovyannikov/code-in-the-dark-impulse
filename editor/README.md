# Редактор

Официальный редактор [Code in the Dark](https://github.com/codeinthedark/editor), переведённый на русский. Один самодостаточный HTML-файл: ACE внутри, зависимостей и интернета не требует.

## Что переведено, а что нет

По-русски — только то, что участник обязан понять под давлением:

| Было | Стало |
|---|---|
| `Finish` | Показать результат |
| `Instructions` | Задание |
| `Reference` | Образец |
| `Unnamed` | Без имени |
| `What's your name?` | Как тебя зовут? |
| подтверждение показа результата | то же, подтверждение словом **да** |
| `Hold your horses!` при закрытии вкладки | Не так быстро! |

Декоративное оставлено как есть: `POWER MODE!`, `Combo` и восклицания турборежима (`Super!`, `Radical!`, …). Причина не только в эстетике: фирменный шрифт редактора **Press Start 2P не содержит кириллицы**, и русский текст в нём проваливается в запасной моноширинный. Чем меньше таких мест, тем целее вид.

## Сборка бандла участника

```sh
./editor/build-bundle.sh round-01
```

Берёт макет из `mockups/round-01/` и собирает `bundles/round-01/`:

```
index.html              редактор, участник открывает только его
assets/page.png         образец (кнопка «Образец»)
assets/instructions.html задание (кнопка «Задание»)
assets/result.html      рамка показа результата
assets/fonts/*.woff2    шрифты макета, если есть
```

Эту папку копируют на флешку — по одной на каждое рабочее место.

Скрипт ругается, если в макете нет шрифтов: образец, снятый в ALS Hauss, а бандл без шрифта — это разные задачи для участника.

## Проверка перед мероприятием

- Открыть `index.html` и пройти весь путь: имя → «Задание» → «Образец» → набор → «Показать результат»
- Убедиться, что кнопки читаются с четырёх метров на внешнем мониторе
- Проверить, что подтверждение показа результата требует именно слова **да**

Редактор при запуске спрашивает имя через `prompt()` — это штатно, но означает, что автоматические скриншоты страницы снять нельзя.
