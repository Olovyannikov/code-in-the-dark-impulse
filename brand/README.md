# Фирменный стиль «Импульс 2026»

Значения считаны напрямую из гайда через Figma MCP.

## Палитра

| Роль | HEX | Имя в гайде |
|---|---|---|
| Фон | `#000000` | чёрный |
| Текст | `#FFFFFF` | White · General/BW/White |
| Акцент | `#1DAFF7` | Cian Primary · Primary Cian · Голубой NEW |
| Вторичный текст | `#AEB1B7` | Grey 5 |

```css
:root {
  --impulse-bg:     #000000;
  --impulse-fg:     #FFFFFF;
  --impulse-accent: #1DAFF7;
  --impulse-muted:  #AEB1B7;
}
```

Чёрный фон с циановым акцентом — удачная рифма к названию активности: вечер в темноте, светится только код.

## Типографика

Фирменный шрифт — **ALS Hauss**.

| Начертание | Где |
|---|---|
| Medium | заголовки, ключевые сообщения, навигация |
| Regular | наборный текст, служебная информация |

Метрики из гайда:

- Кернинг: **−4%** в заголовках, **−2%** в тексте
- Межстрочное: **80–90%** в заголовках, **90–120%** в тексте

Плотный трекинг и сжатый интерлиньяж в заголовках — то, что делает стиль узнаваемым. Если ALS Hauss недоступен для печати, ближайшая замена — любой нейтральный гротеск с геометричными формами, но метрики сохраняем.

## Логотип

«+1» цианом `#1DAFF7`, ставится в правый верхний угол макета.

## Композиция

Из гайда, раздел «Правила композиции»:

> Композиция строится на крупном масштабе и контрасте. Объект может выходить за край кадра, занимать 40–70% площади или становиться абстрактным фоном.

## Источники

- Гайд «Импульс 2026» (внешняя версия) — страницы: `Гайд`, `Макеты`, `Комментарии`
  - Секции: `Мини гайд`, `Гайд Баннеры`, `Преза мерч`, `Логотип`
- Гайдлайн Т1 — страницы: `Гайдлайн Т1`, `Cover`

Оба файла читаются только в копиях: Figma MCP требует edit-доступ, а у оригиналов его нет. Копии лежат в drafts.
