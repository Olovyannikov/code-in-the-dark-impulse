# Памятка участнику

Печатать на A4, по одной на рабочее место. Клеить на раму монитора — так, чтобы видел участник, а не зал.

Вёрстка для печати: чёрный фон, белый текст, цифры и акценты циановые `#1DAFF7`, ALS Hauss Medium. Если принтер только чёрно-белый — инвертировать в белый фон с чёрным текстом, читаемость важнее стиля.

# МЕСТО №___

## ПЕРЕД СТАРТОМ

1. Скопируй папку раунда с флешки к себе
2. Открой **только** `index.html`
3. Переведи браузер в **полноэкранный режим**
4. Убедись, что монитор **дублирует** экран, а не расширяет
5. Жди отсчёта. Не начинай раньше

## ВО ВРЕМЯ РАУНДА

**МОЖНО** — HTML, CSS, ассеты из бандла, смотреть на образец

**НЕЛЬЗЯ** — превью · DevTools · выход из редактора · внешний код · копировать разметку

## КОГДА ВРЕМЯ ВЫШЛО

1. Руки от клавиатуры
2. Сохрани файл
3. Открой результат в браузере
4. Зал голосует

## ПОМНИ

Зал голосует за **похожесть на образец**, а не за чистоту кода.

Сначала крупное: цвет фона, заголовок, композиция. Отступы — потом, если останется время. Их не останется.
