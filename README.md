# Code in the Dark · Импульс 2026

Артефакты дружеской соревновательной активности, которая проходит **в четверг, 19 ноября 2026**, после основной программы конференции «Импульс».

Участники верстают страницу по скриншоту — без превью, без DevTools, без линеек. Пятнадцать минут вслепую, монитор развёрнут в зал, победителя выбирают зрители.

Формат основан на [Code in the Dark](http://codeinthedark.com) (Tictail / Shopify), адаптирован под четыре рабочих места и вечерний слот.

## Формат одной строкой

16 участников · 4 отборочных по 4 человека · финал четырёх победителей · ~1 ч 45 мин
