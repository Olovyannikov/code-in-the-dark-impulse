# Чек-лист техники и площадки

## Железо

- [ ] 4 внешних монитора
- [ ] 4 стола, развёрнутых так, что мониторы смотрят в зал, а ноутбуки — в участников
- [ ] Переходники на каждое место: HDMI, USB-C → HDMI, miniDP → HDMI
- [ ] Удлинители и сетевые фильтры — розеток нужно вдвое больше, чем кажется
- [ ] 4 флешки с бандлами (плюс одна запасная со всеми раундами)
- [ ] Запасной ноутбук, настроенный и с бандлами
- [ ] Большой экран или проектор для таймера, голосования и показа работ
- [ ] Таймер, видимый залу: отдельный экран, проектор или телефон на подставке

## Софт

- [ ] Редактор форкнут из [codeinthedark/editor](https://github.com/codeinthedark/editor), проверен на каждом ноутбуке
- [ ] Бандлы `round-1`…`round-5` + `round-spare` разложены по флешкам
- [ ] Mentimeter: 5 вопросов созданы, ссылка и QR-код подготовлены
- [ ] QR-код голосования распечатан и висит в зале на видном месте

## Прогон накануне (среда)

Не пропускать. Это единственный способ поймать, что у монитора на третьем месте только VGA.

- [ ] Подключить все четыре места и включить **дублирование** экрана
- [ ] Открыть редактор в полноэкранном режиме на каждом — проверить, что выход из фуллскрина заметен залу
- [ ] Прочитать `reference.png` с задних рядов. Не читается — увеличить или поменять макет
- [ ] Прогнать один раунд на себе: 10 минут, реальный бандл, реальный монитор
- [ ] Проверить Mentimeter с телефона, подключённого к гостевому Wi-Fi
- [ ] Замерить, сколько реально занимает посадка четвёрки. Если больше 3 минут — переписать тайминг

## В день, за 2 часа

- [ ] Разложить флешки и памятки по местам
- [ ] Наклеить номера 1–4 на мониторы, крупно, видно из зала
- [ ] Проверить, что Wi-Fi держит зал
- [ ] Зарядить всё
- [ ] Открыть Mentimeter и таймер в отдельных вкладках заранее

## Типичные провалы

| Что | Почему случается | Профилактика |
|---|---|---|
| Нет переходника | У участника свежий MacBook, у площадки только HDMI | Набор переходников на каждом месте |
| Экран расширен, а не продублирован | Так по умолчанию в macOS | Техник проверяет глазами каждое место |
| Образец нечитаем из зала | Скриншот отдали в масштабе 50% | Проверка с задних рядов на прогоне |
| Mentimeter не грузится | Гостевой Wi-Fi режет домен | Проверка накануне + запасной план с руками |
| Таймер видит только ведущий | Забыли вывести на общий экран | Отдельная вкладка на проекторе |
