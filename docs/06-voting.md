# Голосование

Судья — зал. Это принципиально: активность дружеская, и жюри из экспертов превратило бы её в аттестацию.

## Инструмент

**Mentimeter** — бесплатного тарифа хватает. Вопрос типа *Multiple Choice*, четыре варианта по номерам рабочих мест, результаты выводятся на общий экран живым графиком.

Создать **пять отдельных вопросов** заранее — по одному на раунд. Переключать между раундами, а не переиспользовать один: иначе голоса предыдущего отбора останутся в результатах.

Запасной вариант, если с интернетом беда: поднятие рук. Ведущий называет номера по очереди, техник считает. Работает до ~40 зрителей.

## Как формулировать вопрос

> **Чья работа ближе к образцу?**
> 1 · 2 · 3 · 4

Не «чья работа лучше» и не «кто вам больше нравится» — иначе зал голосует за знакомых. Привязка к образцу держит голосование в рамках задачи.

## Порядок

1. Все четыре работы показаны **до** открытия голосования. Иначе первые голоса уходят тому, кого показали первым
2. Рядом с работами держим на экране образец `reference.png` — сравнивать надо с ним
3. Ведущий открывает голосование и даёт 45–60 секунд
4. График выводится на экран, победитель объявляется вслух

## Голосуют все

Участники раунда — тоже зрители, но за себя не голосуют. Проще не проверять, а сказать вслух: «за себя не голосуем», — и этого достаточно.

## Ничья

Поднятие рук между лидерами, считает техник. Если и там поровну — решает ведущий, вслух объясняя выбор. В дружеском формате это нормально и воспринимается спокойно.

## Финал

В финале показываем работы дольше (по минуте на каждую) и даём участникам по одной фразе — что хотели успеть и что решили не делать. После этого голосование на 90 секунд.

## Что фиксировать

После каждого раунда записать распределение голосов. Пригодится, если победитель откажется от финала: вторым местом считается следующий по голосам.

| Раунд | Место 1 | Место 2 | Место 3 | Место 4 |
|---|---|---|---|---|
| Отбор 1 | | | | |
| Отбор 2 | | | | |
| Отбор 3 | | | | |
| Отбор 4 | | | | |
